# Impact & Complexity: FP&A Pillar Anchors

> **Scope:** FP&A-specific anchor examples for calibrating Impact and Complexity scores.
> **Parent Document:** `IMPACT_COMPLEXITY.md` (cross-pillar methodology)

---

## Purpose

This document provides concrete FP&A examples at each Impact and Complexity level. When calibrating new questions or reviewing existing ones, compare against these anchors to ensure consistency.

**Scoring Formula Reference:**
```
Score = (Impact² / Complexity) × CriticalBoost × CombinedMultiplier
```

Impact is squared—high-impact items are disproportionately valuable and worth pursuing even at higher complexity.

When adding new FP&A questions:

- [ ] If borderline, document rationale in the Borderline Examples section
