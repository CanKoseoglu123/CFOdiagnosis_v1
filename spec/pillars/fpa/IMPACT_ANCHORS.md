# FP&A Pillar — Impact & Complexity Anchors

**Purpose:** Calibration examples for FP&A questions at each Impact and Complexity level.
**Scope:** FP&A-specific anchor examples only.
**Methodology:** See `IMPACT_COMPLEXITY.md` for cross-pillar scoring definitions.

---

## How to Use This Document

When adding or reviewing FP&A questions:
1. Draft your Impact and Complexity scores
2. Find similar questions in the anchors below
3. Ask: "Is my question truly in the same tier?"
4. Adjust if needed

- [ ] Apply "CFO test" — would a CFO agree?
- [ ] If borderline, document in Borderline Cases section
